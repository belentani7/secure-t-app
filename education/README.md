# SECURE T · ACADEMIA

SECURE T incorpora una capa educativa modular para convertir conocimiento técnico, IA, ciberseguridad y alfabetización digital en itinerarios prácticos.

## Principios
- **Aprender haciendo:** cada unidad termina en una evidencia o microproyecto.
- **De cero a profesional:** lenguaje accesible sin sacrificar profundidad técnica.
- **Seguridad primero:** laboratorios defensivos, legales y aislados.
- **Contenido vivo:** los enlaces externos se conservan como recursos/clases; no se descargan ni redistribuyen vídeos de terceros.
- **Microlearning + profundidad:** lección breve → práctica → evaluación → proyecto.
- **Multilingüe:** estructura preparada para español, portugués e inglés.

## Modelo de una clase
Cada clase puede representarse como datos y renderizarse en la interfaz:

`objetivo → prerequisitos → teoría → vídeo/recurso → laboratorio → quiz → evidencia → siguiente nivel`

Para vídeos externos, almacenar únicamente metadatos y URL: título, proveedor, autor, duración si está disponible, idioma, nivel, objetivos, timestamps útiles y licencia/origen. Nunca descargar ni alojar copias sin permiso.

## Niveles
- **L0:** alfabetización
- **L1:** fundamentos
- **L2:** práctico
- **L3:** profesional
- **L4:** avanzado/especialización
- **L5:** proyecto/capstone

## Evidencias
Cada ruta genera un portfolio verificable: cuestionarios, diagramas, informes de laboratorio, configuraciones seguras, repositorios, playbooks, threat models y proyectos finales.
