# SECURE T · CATÁLOGO DE CLASES EN VÍDEO

Este catálogo convierte vídeos externos encontrados en el corpus de investigación en **clases enlazadas**, no en archivos descargados. El sistema debe enriquecer cada enlace con contexto pedagógico.

## Pipeline de ingestión

1. **Descubrir** → URL/título/fuente.
2. **Clasificar** → track, módulo, nivel y competencias.
3. **Validar** → fuente, autor, fecha y disponibilidad.
4. **Pedagogizar** → objetivo + resumen + conceptos + preguntas.
5. **Conectar** → prerrequisitos y siguientes clases.
6. **Practicar** → ejercicio/laboratorio relacionado.
7. **Evaluar** → quiz y evidencia.
8. **Actualizar** → comprobar enlaces y vigencia periódicamente.

## Regla de derechos

Un vídeo de YouTube, Vimeo, curso externo u otra plataforma se integra como **recurso educativo externo** mediante enlace y atribución. SECURE T no debe descargar, copiar, re-subir ni almacenar el archivo audiovisual de terceros salvo que exista autorización/licencia que lo permita.

## Conversión de vídeo → clase

**Antes:** “ver vídeo”.

**Después:**

`VÍDEO EXTERNO → contexto → objetivos → guía de observación → notas → quiz → práctica → evidencia → certificado/avance`

Esto permite que un enlace de 20 minutos produzca una experiencia educativa completa sin apropiarse del vídeo original.
