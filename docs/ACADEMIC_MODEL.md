# Modelo académico

Cada unidad sigue `Theory → Practice → Lab → Evidence → Assessment → Competency`. El progreso no se reduce a un porcentaje: se expresa mediante competencias, evidencias, rúbricas, confianza y nivel de dominio.

## Entidades

`users`, `profiles`, `roles`, `students`, `faculty`, `programs`, `degrees`, `courses`, `modules`, `lessons`, `learning_objectives`, `competencies`, `enrollments`, `attempts`, `submissions`, `assessments`, `grades`, `evidence`, `projects`, `certificates` y `credentials`.

## Evidencia

Una evidencia debe indicar autor, objetivo, contexto, artefacto, fecha, rúbrica, revisión y estado. Las recomendaciones deben explicar qué debilidad o prerrequisito las originó.

## Currículo

El programa de referencia contiene cuatro años: fundamentos de Linux, redes, Python, sistemas operativos, web y criptografía; seguridad web, cloud, forense, identidad, SOC e inteligencia de amenazas; reverse engineering, malware, detection engineering, respuesta a incidentes y seguridad de IA; red/blue/purple team, arquitectura, investigación y capstone.

## Credenciales

Se separan achievement, certificate, credential y verification. La capa futura se alinea con Open Badges 3.0 y Verifiable Credentials, sin afirmar validez universitaria automática.
