# secure T

Universidad digital de ciberseguridad e inteligencia artificial. Esta repo nace como un producto separado de `lingua-aberta`.

## Dirección de producto

El objetivo es construir una plataforma académica real con currículo de cuatro años, laboratorios aislados, evaluación por evidencia, faculty, comunidad, expediente persistente, credenciales verificables, interoperabilidad LTI y tutor IA con voz sintética transparente.

## Estado inicial

La base actual contiene el campus responsive, progreso de aprendizaje, tutoría y API Express local. El siguiente hito es sustituir el estado local por PostgreSQL/Drizzle, autenticación, RBAC y datos académicos persistentes.

## Voz abierta prevista

La evaluación inicial considera Kokoro para síntesis eficiente y Chatterbox-Turbo para mayor expresividad. La elección dependerá de licencia, idioma, latencia, hardware y consentimiento.
